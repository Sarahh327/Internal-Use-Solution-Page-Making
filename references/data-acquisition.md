# 按业务场景表达数据采集与集成

来源：用户确认 EAM、WMS、EMS 均需在 UNS 处简要说明数据接入；不同业务自行归纳合适的数据来源与采集方式。这里是方案写作规则，不代表现场已完成连接。

## 固定模块要求

- 数据采集与 UNS 和 Builder、UNS Agent 一起构成每个方案必有的三大业务模块；底部服务模式另外固定保留。不能以截图未覆盖接入、文案精简或更换软件名称为由省略。
- 模块使用 `id="namespace"`。包含数据源、采集/接口方式、UNS 对象关系及应用用途；图形与短文可合并，保留项目已确认的视觉布局，不要求所有软件复制 EAM 图形。
- 新写 HTML 的数据来源节点使用 `data-uns-source`，业务对象模型容器使用 `data-uns-model`，两者保留可读文本。兼容已确认 EAM 的 `.eam-source` / `.uns-model` 结构；这些标记用于完整性检查，不证明真实连接或业务模型有效。

## 页面表达

- 每个方案的 UNS 版块都带出数据接入，用一句话配紧凑的数据来源图；默认约 2–3 类来源，不扩成协议手册或独立长篇章节。
- 图中表达“来源与数据 → 采集/接口 → UNS 业务对象 → 应用或 Agent”。可以与已有业务树合并，避免重复画同一流程。
- 简述 Tier0 原生支持常用工业协议和系统接口。只展示当前业务相关、产品资料支持的方式；协议支持不等于专用连接器已配置，也不等于该项目已经接入。
- 从业务问题反推数据：谁采集什么、用什么接口、按什么对象关联、用于什么判断。不能所有应用照抄同一组 PLC、MES、ERP 图标。

## 场景选择示例

以下是设计候选，依据实际设备接口、截图与业务描述取舍；不要将一行中的全部来源当作必配项。

| 应用 | 主要来源与数据 | 采集或集成方式 | 业务用途与可选关联 |
|---|---|---|---|
| EAM 设备管理 | 设备/PLC 的状态、运行时长、温度、报警；状态传感器的振动与轴承温度；人工巡检、维修记录 | 设备可用 OPC UA / Modbus；传感器可经网关以 MQTT / Modbus 接入；人员通过表单录入 | 按设备编码关联运行与维护记录。按需接 MES 的生产安排/停机记录来安排维护窗口；接 ERP 的资产/备件信息来准备物料与核算成本 |
| WMS 仓库管理 | 扫码枪/PDA 的物料、批次、容器、库位与收发确认；上游订单和生产信息 | 扫码设备通过其实际支持的键盘输入、终端应用或 SDK/API 传入业务页面；MES/ERP 可通过开放 API、数据库或约定文件交换 | 按单据、物料、批次、容器关联收货、上架、拣货与发货。订单来源由当前仓储场景决定，不把扫码枪统一写成 MQTT 设备 |
| EMS 能源管理 | 电表及水、气、热计量装置的累计量、流量、功率等 | 根据仪表与网关选择 Modbus、MQTT、OPC UA 等；仅在楼宇设备接口适用且产品支持时列 BACnet | 按计量点、区域、设备与时间关联能耗。分析单位产品能耗时，才按需关联产量、班次或生产记录 |

## 集成边界与数据关联

- 外部业务系统有具体用途才列出，并用“按需”或“可选”表达。EAM 的 MES/ERP 用于生产安排、资产及备件关联，不是运行 EAM 的前提；主要视觉仍突出设备、传感器与维护记录。
- 说明需要的数据类别即可，不臆定所有企业由同一个系统负责设备台账、备件或工单。已有 EAM 自身维护的信息不必为了凑架构再假设来自 ERP。
- 根据场景选择关联键：EAM 的设备编码，WMS 的单据/物料/批次/容器，EMS 的计量点和时间。必要时点出时间、单位或编码对齐，避免堆接口实施细节。
- 采集链路和 Agent 示例保持一致：问题涉及的字段应存在于所示 UNS 模型或明确的数据来源中。查询示意不暗示拥有设备控制、回写 ERP 或自动派工权限。
- 未知的现场连接在交接说明中记为待确认；正常方案设计可据资料提出合理候选，不因此停止制作 HTML。不得把候选写成已上线能力。

## 产品证据与交付核对

- 官方能力参考：[Tier0 Data Collection](https://tier0.app/product/tier0-platform/data-collection)。2026-09-20 已核对常用 OPC UA、MQTT、Modbus 与 API/数据库等接入描述；新增具体协议、专用连接器或需要确认现状时重新核实官方资料。
- 区分官方平台能力、场景设计推断与现场已验证连接；后者必须有对应资料。正文保持简练，详细协议依据和待确认项放交接说明。
- 中文修改落实到当前主 HTML 及其源文件，不能只保存在未展示的试验页面；双语打包时同步正文、接入图、标签、可访问文本与相关 Agent 描述。

## 可操作呈现

数据来源图和业务树默认做成可点击模型：选择来源查看采集方式与目标主题，展开业务对象与字段。按 [交互式界面模型](interactive-demos.md) 保留可读首态并验证操作结果；连接状态是示例，不伪装实时接入。配置生成器可从同一份来源映射生成 Namespace 与 Agent。
